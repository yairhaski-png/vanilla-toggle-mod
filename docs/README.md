# VEXO – ספר קולקציה

פתחו את `index.html` בדפדפן (אפשר גם לגלול עם החיצים במקלדת).

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | המצגת: שער, מערכת לוגואים, כל 22 החולצות (שם, מחיר, המלצה, קהל, חזית+גב, הורדות), מוצרים נוספים, סיכום מחירים |
| `downloads/<חולצה>/` | לכל חולצה: תמונת חזית/גב לאתר (JPG 1400×1600), קבצי הדפסה שקופים (PNG, 300dpi) וחבילת ZIP |
| `downloads/merch/` | כובע, ספל, תיק, מדבקה וכיסוי טלפון לחמשת הלוגואים האהובים |
| `logos/` | כל הלוגואים והסמלים ב־PNG שקוף 2000px (סגול, ולרקע כהה) |
| `vexo-all-designs.zip` / `vexo-logos.zip` | הכל / רק הלוגואים |
| `vexo-catalog.csv` | קטלוג: שם, מחיר, צבע, קהל יעד |

## בנייה מחדש
```
npm i playwright            # בתיקייה כלשהי, ואז NODE_PATH לתיקייה הזו
node tools/build.js         # יוצר תמונות + index.html
python3 tools/zip.py        # יוצר את קבצי ה-ZIP
```
עריכת חולצות: `tools/data.js` · עריכת לוגואים: `tools/art.js` · עיצוב המוקאפים: `tools/mockups.js`.
